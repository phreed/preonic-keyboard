= FreedBoard Keyboard Project
:toc: left
:toclevels: 3
:source-highlighter: highlight.js
:icons: font

A modern keyboard layout for the https://olkb.com/collections/preonic[Preonic rev3] ortholinear keyboard,
implemented in QMK firmware with advanced modifier handling and six functional layers.

== Quick Start

This project uses https://pixi.sh[pixi] for dependency management and task automation.

Install pixi if you haven't already:

[source,bash]
----
curl -fsSL https://pixi.sh/install.sh | bash
----

Then run the full build pipeline:

[source,bash]
----
pixi run workflow
----

== Available Tasks

[cols="1m,3",options="header"]
|===
| Task | Description

| generate-phreedom
| Compile `freed-board.toml` → `freed-board.json` (QMK Configurator format)

| generate-svg
| Generate SVG layer visualizations from `freed-board.json`

| build-pdf
| Build PDF documentation from `freed-board.adoc`

| build-html
| Build HTML documentation from `freed-board.adoc`

| build-docs
| Build both PDF and HTML documentation

| build-all
| Generate SVGs and build PDF (`ensure-dirs` → `generate-phreedom` → `generate-svg` → `build-pdf`)

| lint-config
| Lint `freed-board.json` using the QMK CLI

| compile-firmware
| Compile QMK firmware from `freed-board.json`

| flash-keyboard
| Flash the keyboard (requires a connected device)

| workflow
| Full pipeline: `lint-config` → `build-all` → `compile-firmware`

| clean
| Remove all generated files (SVGs, PDF, firmware binaries)

| check-qmk
| Verify QMK installation and environment

| validate-svg
| List generated SVG files and confirm count

| info
| Display keyboard configuration via `qmk info`
|===

== Editing the Layout

The canonical layout source is `freed-board.toml`.
Edit `src/freed-board.toml`, then regenerate `freed-board.json`:

[source,bash]
----
pixi run generate-phreedom
----

=== TOML Format

The TOML file organises each layer as five named rows (`row0`–`row4`), each containing exactly 12 key entries:

[source,toml]
----
[[layers]]
name = "base"

# Number row
row0 = ["KC_1", "KC_2", "KC_3", "KC_4", "KC_5", "KC_GRV", "KC_QUOT",
         "KC_6", "KC_7", "KC_8", "KC_9", "KC_0"]

# Top alpha row — modifier combos expressed as inline tables
row1 = [
  "KC_Q", {key="KC_W", mod="LGUI"}, {key="KC_E", mod="LALT"}, {key="KC_R", mod="LCTL"},
  "KC_T", "KC_MINS", "KC_EQL",
  "KC_Y", {key="KC_U", mod="RCTL"}, {key="KC_I", mod="RCTL"}, {key="KC_O", mod="RCTL"}, "KC_P",
]
----

Modifier combos use an inline table with `key` and `mod` fields.
The generator converts `{key="KC_W", mod="LGUI"}` → `"LGUI(KC_W)"` in the JSON.

=== Layer Summary

[cols="1,1m,3",options="header"]
|===
| # | name | Purpose

| 0 | base       | Default alphanumeric layer with homerow modifier combos
| 1 | shift      | Shifted symbols; activated by `SC_LSPO` / `SC_RSPC`
| 2 | function   | F-keys and one-shot hardware modifiers; activated by `MO(2)`
| 3 | numpad     | Numeric keypad; activated by `MO(3)`
| 4 | navigation | Arrow cluster and page keys; activated by `MO(4)`
| 5 | system     | Boot, reset, EEPROM clear, debug toggle; activated by `MO(5)`
|===

== Manual Usage

=== Prerequisites

* Python 3.11+ (or Python 3.8+ with `pip install tomli`)
* https://docs.qmk.fm/#/newbs[QMK CLI] — `pip install qmk`
* Asciidoctor and asciidoctor-pdf

=== Generate JSON from TOML

[source,bash]
----
python scripts/gen-json-board.py
----

=== Generate SVG Visualizations

[source,bash]
----
python scripts/gen-vis-board.py freed-board.json \
    src/layout-templates/LAYOUT_ortho_5x12-template.svg
----

=== Build Documentation

[source,bash]
----
asciidoctor-pdf src/freed-board.adoc -o gen/freed-board.pdf
asciidoctor src/freed-board.adoc -o gen/freed-board.html
----

=== QMK Commands

[source,bash]
----
qmk lint freed-board.json
qmk compile freed-board.json
qmk flash freed-board.json
----

== SVG Template Format

The template (`layout-templates/LAYOUT_ortho_5x12-template.svg`) uses `{{placeholder}}` syntax:

[cols="1m,3",options="header"]
|===
| Placeholder | Content

| {{LAYER_TITLE}}
| Main title, e.g. `phreedom - Layer 0`

| {{LAYER_SUBTITLE}}
| Subtitle, e.g. `Layout: LAYOUT_ortho_5x12`

| {{KEY_N}}
| Primary label for key at index N (0–59)

| {{SUB_N}}
| Secondary (smaller) label for key at index N
|===

=== Notable QMK Keycode Mappings

| KC_RGHT | →

== Troubleshooting

JSON parse error::
  Validate with `python -m json.tool freed-board.json`.
  The JSON is generated — edit `freed-board.toml` instead.

TOML row length error::
  Each of `row0`–`row4` must contain exactly 12 entries.
  The generator reports the offending layer and row.

Missing key labels in SVG::
  Unknown keycodes render as truncated raw text.
  Add mappings to `QMK_KEYCODE_MAP` in `scripts/gen-vis-board.py`.

QMK not found::
  Run `pixi run check-qmk` to diagnose, or `pip install qmk` manually.
